# Find Near Places 📍

A responsive location-based web application that helps users discover nearby businesses and places of interest using the Google Places API.

## 🔗 Live Demo
[View Live Application](вставь-ссылку-после-деплоя)

## 🛠 Built With
- **Next.js**
- **TypeScript**
- **Tailwind CSS**
- **Google Places API**

## ✨ Features
- Real-time search for nearby businesses based on user location
- Clean, responsive user interface
- Asynchronous API integration with error handling

## 🚀 Getting Started
1. Clone the repository: `git clone https://github.com`
2. Install dependencies: `npm install`
3. Add your Google API key to `.env.local`
4. Run the development server: `npm run dev`
